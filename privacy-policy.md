# Политика конфиденциальности приложения «Рядом»

Дата вступления в силу: 26 августа 2026 г.

Приложение «Рядом» (далее — «Приложение») помогает пользователям находить и оказывать взаимопомощь (еда, одежда) на локальном уровне. Используя Приложение, вы соглашаетесь со сбором и обработкой данных, описанных ниже.

## 1. Какие данные мы собираем

- **Номер телефона** — используется для регистрации и входа через SMS-код (OTP).
- **Геолокация** — используется для отображения запросов о помощи поблизости от вас и для указания вашего местоположения при создании запроса. Вы можете вручную скорректировать точку на карте.
- **Данные профиля** — имя, роль (Нуждающийся / Помогающий), история запросов и откликов.
- **Отзывы** — оценки и комментарии, которые пользователи оставляют друг другу после завершения запроса.

## 2. Как мы используем данные

- Для аутентификации пользователей (SMS-код через сервис Mobizon).
- Для отображения запросов о помощи в зависимости от расстояния до пользователя.
- Для связи между Нуждающимся и Помогающим в рамках запроса.
- Для отображения рейтинга и отзывов на странице профиля.

## 3. Передача данных третьим лицам

- Номер телефона передаётся провайдеру SMS-рассылки **Mobizon** исключительно для отправки кода подтверждения.
- Мы не продаём и не передаём ваши данные третьим лицам в рекламных целях.

## 4. Пожертвования

Приложение содержит кнопку добровольного пожертвования «💛 Помощь проекту» с переводом через Kaspi. Мы не храним данные ваших банковских карт — перевод осуществляется через приложение Kaspi.

## 5. Хранение и защита данных

Данные хранятся на защищённых серверах (Railway). Мы принимаем разумные технические меры для защиты данных от несанкционированного доступа.

## 6. Права пользователя

Вы можете:
- запросить удаление своего аккаунта и связанных данных;
- отозвать согласие на использование геолокации через настройки устройства;
- обратиться с вопросами по обработке данных по контакту ниже.
